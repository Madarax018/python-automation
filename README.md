# Python Automation

A beginner-friendly file organizer.

Run: python main.py FOLDER

Test on a copy of your files first.

## Installation

Clone the repository:

```bash
git clone https://github.com/Madarax018/python-automation.git
cd python-automation
```

## Running the project

Run `python main.py /path/to/test-folder`.

## Automated testing

Run the tests locally:

```bash
python -m unittest discover -s tests -v
```

GitHub Actions runs these tests automatically when
changes are pushed or a pull request is opened.
